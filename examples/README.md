# 实际玻璃库示例

人工操作时直接选择自己已安装软件中的原库文件：

- Zemax：实际使用的 `Glasscat` 目录中的 `.AGF`。在软件设置中核对 Glasscat 路径。
- CODE V：安装目录 `glass/` 中的 `.xml`，例如 `CDGM.xml`、`SCHOTT.xml`。

开发机本地只在 `Zemax/`、`CODEV/` 中各保留一个原文件副本，来源及 SHA256 存在同目录的本机来源记录中。文件名保留原版名称，不将转换结果混入输入示例。

厂家 MA/A/B/C/D 来自另行选择的厂家参数表，其版本可能与软件原库不同。请先核对匹配统计和报告来源。CODE V → AGF 时，多厚度透过率必须选择要保留的厚度。

本仓库不分发第三方玻璃库、厂家表和软件总表。测试用的合成材料定义在 `tests/catalog_fixtures.py`，无需安装 Zemax/CODE V 即可运行。
